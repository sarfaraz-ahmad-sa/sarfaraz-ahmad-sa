# Sarfaraz Ahmad — Portfolio Website

A responsive, dependency-free static website for GitHub Pages.

## Preview locally

Open `index.html` in your browser, or from the `docs` folder run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish using GitHub Pages

1. Add the `docs/` folder to your existing `sarfaraz-ahmad-sa/sarfaraz-ahmad-sa` repository and commit/push it to the default branch.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the **/docs** folder, then **Save**.
5. Your expected URL is `https://sarfaraz-ahmad-sa.github.io/sarfaraz-ahmad-sa/` once Pages deployment succeeds.

Edit contact details, project descriptions and links in `index.html`. No client code or private datasets are included.
